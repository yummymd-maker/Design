# VeDesign Web Components 文档索引

这里完整复制 `@ve-design/web` 的 Web Components 组件文档。使用普通 HTML、Web Components、跨框架或无 React 环境时读取本目录。

按需读取对应组件文档；不要一次性加载整个目录。

选择组件时，先看「适用场景」判断是否匹配，再打开对应组件文档查看 props、slot、事件和案例。
